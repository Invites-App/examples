# Примеры Invites

Как добавить Invites на свой сайт. Посмотреть, как это работает: https://invites-app.github.io/examples/

Если что-то не работает, напишите нам в [@InvitesSupportBot](https://t.me/InvitesSupportBot).

## Кнопка «Купить билет»

Кнопка открывает поверх вашего сайта окно с событием: гость регистрируется и оплачивает билет, не уходя с сайта. Вставьте на страницу этот код со ссылкой на своё событие:

```html
<a
  href="https://tginvites.com/e/ID-СОБЫТИЯ"
  class="invites-checkout--button"
  data-invites-checkout
>
  Купить билет
</a>

<script
  async
  src="https://tginvites.com/widget.js">
</script>
```

Код с уже подставленной ссылкой есть в Invites: откройте своё событие → «Управление» → «Виджет для сайта» и нажмите «Скопировать код». Там же видно, сколько раз открывали окно и сколько гостей записались через кнопку.

### Подробнее

**Несколько кнопок.** Скрипт `<script>` достаточно подключить на странице один раз. Если он окажется на странице несколько раз, ничего не сломается.

**Свой стиль.** Уберите `class="invites-checkout--button"`, и кнопка останется без наших стилей: оформите её, как остальные кнопки сайта.

**Любой элемент.** Атрибут `data-invites-checkout` можно поставить на любой элемент, не только на ссылку. Если у элемента нет `href`, укажите ссылку на событие в самом атрибуте:

```html
<button type="button" data-invites-checkout="https://tginvites.com/e/ID-СОБЫТИЯ">
  Записаться
</button>
```

**Кнопки, которые появляются позже.** Если страница добавляет кнопки после загрузки (конструкторы сайтов, React, Vue), ничего вызывать не нужно: скрипт сработает и на них.

**Открыть из своего кода.** Окно можно открыть из JavaScript:

```js
window.InvitesWidget && window.InvitesWidget.open("https://tginvites.com/e/ID-СОБЫТИЯ");
```

Скрипт подключается с `async`, поэтому сразу после загрузки страницы `window.InvitesWidget` может ещё не быть.

**Если скрипт не загрузился.** Кнопка — обычная ссылка: без скрипта она откроет страницу события на tginvites.com. Так же она открывается, если нажать на неё с Ctrl, Cmd или Shift.

## Как устроен этот пример

Весь пример — один файл [`index.html`](index.html) без сборки, его показывает GitHub Pages. Откройте его исходный код, чтобы посмотреть, как подключены кнопки.
