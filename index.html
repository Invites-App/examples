Примеры Invites

Кнопка «Купить билет» для вашего сайта: она открывает окно с событием поверх сайта, и гость регистрируется и оплачивает билет, не уходя со страницы.

Инструкция и код примеров — в репозитории на GitHub.

Кнопка Invites

Код из раздела «Виджет для сайта» в Invites. Скрипт подключается на странице один раз, сколько бы кнопок на ней ни было.

Записаться 
<a
  href="https://tginvites.com/e/d8"
  class="invites-checkout--button"
  data-invites-checkout
>
  Записаться
</a>

<script
  async
  src="https://tginvites.com/widget.js">
</script>

Своя кнопка

Без class="invites-checkout--button" наших стилей у кнопки нет: оформите её, как остальные кнопки сайта.

Записаться → 
<a
  href="https://tginvites.com/e/d8"
  class="my-button"
  data-invites-checkout
>
  Записаться →
</a>

Любой элемент

data-invites-checkout работает на любом элементе. Если у элемента нет href, ссылка на событие указывается в самом атрибуте. 

<button
  type="button"
  class="event-card"
  data-invites-checkout="https://tginvites.com/e/d8"
>
  …
</button>

Из своего кода

Окно можно открыть из JavaScript. Скрипт загружается асинхронно, поэтому сначала проверьте, что window.InvitesWidget уже есть. 

document.getElementById("open-from-code").addEventListener("click", () => {
  window.InvitesWidget &&
    window.InvitesWidget.open("https://tginvites.com/e/d8");
});
